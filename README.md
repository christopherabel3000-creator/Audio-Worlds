# Audio Worlds

A collection of screen-reader-accessible audio games, playable in the browser.

## Games
- **Signal Line** (`signal-line/`): drive a train for 90 seconds; up and down arrows control power and brakes; never pass a red signal.
- **Street Crossing** (`street-crossing/`): cross four lanes and a median and back, four times in 30 seconds, without getting hit.
